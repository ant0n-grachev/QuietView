# Privacy policy

QuietView processes browser-state and display properties locally to substitute selected values exposed to websites.

The extension does not record browsing history, page content, or form input. It has no analytics, persistent data storage, remote code, or data uploads. No extension data is sold or shared.

Site access is used to run the masking script on permitted pages and frames. You control this access through Chrome’s extension settings. File access is optional for local diagnostic pages.

The extension does not change how websites themselves collect data. See [known limitations](docs/DETAILS.md#important-limits-and-possible-breakage).
